# Security model

| Threat | Mitigation | Residual |
|---|---|---|
| modified model | `blockRoot` | not biological truth |
| modified runtime | `runtimeHash` | commodity device trust |
| deleted receipts | hash chain + later anchor | tail before anchor |
| floating-point divergence | Q16.16 fixed-point | operator limits |
| payment latency | settlement outside loop | offline license policy |

Attestation ≠ physical reality. Replay proves deterministic computation on committed inputs.
